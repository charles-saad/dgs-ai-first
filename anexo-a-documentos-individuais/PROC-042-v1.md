# PROC-042-v1 — Procedimento de Cálculo de Frete Especial
**Versão:** v1  
**Emissão:** Agosto/2023  
**Responsável:** Operações

## 1. Objetivo
Definir o procedimento de cálculo de frete para cargas especiais (acima de 500kg).

## 2. Fórmula de Cálculo

### 2.1 Fórmula base
Valor do frete = Valor base × Multiplicador regional × Fator de peso

### 2.2 Multiplicadores regionais (versão agosto/2023)

| Região | Multiplicador |
|--------|--------------|
| Sul | 1,0 |
| Sudeste | 1,1 |
| Centro-Oeste | 1,3 |
| Nordeste | 1,5 |
| Norte | 1,6 |

### 2.3 Fatores de peso

| Faixa de peso | Fator |
|---------------|-------|
| 500kg a 1.000kg | 1,0 |
| 1.001kg a 2.000kg | 1,2 |
| 2.001kg a 5.000kg | 1,5 |
| Acima de 5.000kg | 2,0 |

Substituído pela versão v2 (novembro/2023).
