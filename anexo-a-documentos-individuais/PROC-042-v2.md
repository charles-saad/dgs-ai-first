# PROC-042-v2 — Procedimento de Cálculo de Frete Especial
**Versão:** v2 (revisada)  
**Emissão:** Novembro/2023  
**Responsável:** Operações

## 1. Objetivo
Definir o procedimento de cálculo de frete para cargas especiais (acima de 500kg ou com características especiais de transporte).

## 2. Fórmula de Cálculo

### 2.1 Fórmula base
Valor do frete = Valor base × Multiplicador regional × Fator de peso

### 2.2 Multiplicadores regionais (versão revisada — novembro/2023)

| Região | Multiplicador |
|--------|--------------|
| Sul | 1,0 |
| Sudeste | 1,2 |
| Centro-Oeste | 1,4 |
| Nordeste | 1,6 |
| Norte | 1,8 |

### 2.3 Fatores de peso

| Faixa de peso | Fator |
|---------------|-------|
| 500kg a 1.000kg | 1,0 |
| 1.001kg a 2.000kg | 1,2 |
| 2.001kg a 5.000kg | 1,5 |
| Acima de 5.000kg | 2,0 |

### 2.4 Exemplo de cálculo
Para 600kg com destino a Manaus (Região Norte):
- Multiplicador regional: 1,8
- Fator de peso: 1,0
- Valor do frete = Valor base × 1,8 × 1,0 = Valor base × 1,8

## 3. Consulta do Valor Base
O valor base é atualizado mensalmente e deve ser consultado na tabela mensal de fretes disponível no sistema de gestão.

## 4. Vigência
Este procedimento substitui a versão v1 (agosto/2023).
